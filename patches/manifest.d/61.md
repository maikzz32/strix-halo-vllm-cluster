# 61_glm53_awq_weight_remap.py

- **Purpose:** Make the local GLM-5.3-Flash int4 re-quant
  (`/home/maik/glm53_flash`, based on cyankiwi/GLM-5.3-Flash-AWQ-INT4) load on
  the PR #53906 glm5next loader. Two adaptations in
  `vllm/models/glm5next/nvidia/model.py`:
  1. **Name remap** (AWQ-era -> upstream names): `attn_hc.*` ->
     `hc_attn_*`, `ffn_hc.*` -> `hc_ffn_*`, `self_attn.forget_gate.X` ->
     `self_attn.X`, fused `conv1d` [3*8192] -> `{q,k,v}_conv1d` [8192] each
     (order assumed q,k,v — fails loudly on the first prompt if wrong).
  2. **Load-time int4 dequant** of the attention projections the model class
     builds unquantized (`quant_config=None` hard-coded for KDA *and* MLA
     projections — "BF16 in checkpoint"), but the re-quant packed:
     `self_attn.{q,k,v,o,kv_b,q_b}_proj`. llm-compressor pack-quantized int4,
     group 32, asymmetric; zp nibbles packed along the OUTPUT dim (needs a
     permute on unpack — plain reshape mixes block/group axes). Synthetic
     roundtrip-verified (every element within its group quant bound). MoE
     experts stay packed (TRITON WNA16 handles them).
- **Runtime-first provenance:** developed and validated live in the running
  containers as `patches/runtime_glm53_awq_remap.py` (versions v1 -> v2.2)
  against `ghcr.io/maikzz32/strix-vllm-gfx1151:dev-glm53-flash`; this file is
  the baked form. Failure chain that drove it: `attn_hc.base` KeyError ->
  `kv_b_proj.weight_packed` KeyError (sparse layer 3) ->
  `in_proj_qkvbfg_a.weight_packed` KeyError (KDA layer 4).
- **Target:** `vllm/models/glm5next/nvidia/model.py` (anchor: the
  `load_weights` def + `stacked_params_mapping` line, exactly 1 match).
- **SKIP semantics:** no glm5next package (stable/main builds) -> SKIP 0.
  glm5next present but anchor moved -> exit 42. `ast.parse` before write.
- **Re-audit trigger:** exit 42, or new KeyErrors for weights not covered by
  the rename/dequant tables (e.g. if the re-quantizer changes naming).
- **Note:** `patches/runtime_glm53_awq_remap.py` remains as the runtime-only
  variant for already-running containers (not globbed by apply_all.sh).
- **Date:** 2026-09-01.
