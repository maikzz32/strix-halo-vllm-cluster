## 59_platform_fastpath.py

- **Purpose:** Short-circuit vLLM's platform detection on Strix Halo.
  `vllm/platforms/__init__.py::resolve_current_platform_cls_qualname`
  probes TPU (libtpu import), CUDA (pynvml init/shutdown), ROCm (amdsmi
  init/shutdown), XPU and CPU in sequence on **every** process start —
  engine, CLI, Ray worker. There is no upstream short-circuit for ROCm
  (vllm#32730 confirmed the same hole for CPU).
- **Target:** `vllm/platforms/__init__.py` — inserts a guarded early
  return at the top of `resolve_current_platform_cls_qualname()`.
- **Benefit class:** saves hundreds of ms per process start (amdsmi
  init/shutdown dominates on ROCm stacks) and removes whole failure
  modes: pynvml import/init on a ROCm-only box, amdsmi probing on a
  partially broken ROCm install, libtpu import cost. On a 4-node
  cluster with per-worker spawns this multiplies.
- **Env knob:** `VLLM_GFX1X_FAST_PLATFORM=1` enables the fast path
  (lazy read at detection time, like the other `VLLM_GFX1X_*` knobs);
  unset/0 restores stock behavior.
- **Risk / fallback (preserved):** the fast path fires only when
  `/dev/kfd` exists, i.e. a ROCm device is actually present. Otherwise
  it falls through to the stock probe chain, so GPU-less container
  builds and `docker/smoke_test.sh` keep working and the
  `UnspecifiedPlatform` fallback survives. Deliberately not portable —
  this build targets gfx1151 only (owner directive).
- **Status:** expected-to-need-adjustment. Anchor verified against vLLM
  dev tag v0.28.1rc0 (79651d6085885cf2842baf85526ece7afa87c87d).
  `ast.parse` fail-closed before writing.
- **Re-audit trigger:** exit 42 (`resolve_current_platform_cls_qualname`
  anchor gone or duplicated, `vllm/platforms/__init__.py` moved, patched
  file fails `ast.parse`), or upstream landing a native ROCm
  short-circuit (then this patch is obsolete).
- **Validate on hardware:** startup time delta with
  `VLLM_GFX1X_FAST_PLATFORM=1` vs. unset (expect hundreds of ms per
  spawn), `vllm` CLI and engine both resolving `RocmPlatform`, and
  GPU-less container build + `docker/smoke_test.sh` still passing
  (fallback path).
- **Date:** 2026-09-01.
