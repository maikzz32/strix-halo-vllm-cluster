# W2 plus AVX-512: combined model comparison

With serial W2 enabled throughout, changing only the UMA native library to the
already numerically validated AVX-512 implementation improves measured decode
speed by about 2%. Weights, quantization, original W1, context and MTP3 remain
fixed. All 48 texts, input/output token lengths and speculative statistics are
identical across the three runs.

| Configuration | Output tokens/s | Mean TPOT (ms) |
|---|---:|---:|
| W2 + AVX2 before | 53.9806 | 16.3995 |
| W2 + AVX-512 | 54.6905 | 16.0871 |
| W2 + AVX2 after | 53.8731 | 16.4058 |

Against the stronger before control the candidate provides 1.315% more overall
throughput and 1.942% faster decoding. The two controls differ by 0.199% in
overall throughput. Six matched 512-token streams give a median 1.651% decode
gain, with identical request bodies, content, reasoning, usage and finish
reasons. This is a small consistent gain in these runs, not a statistical
confidence bound or achievement of the 60 output-token/s goal.

All three ShareGPT48 C1 runs complete with zero failures and independent success
counter deltas of exactly 48. Queues are empty before and after. Fresh runtime
evidence for candidate and restored control verifies every rank's mapped
library, source hash, W2 flag and 32-bank eager/graph parity against active
PyNccl. The candidate finished its six streams at counter 54 and was stopped
cleanly on all four nodes.

Canonical W2/AVX2 remains active as run
`4ce67280916a43c4bd7e9b13d8d381ad`, idle at counter 54 after the after-control
streams. The canonical configuration was never overwritten. The separate
candidate file is `config/w2-avx512-combined-r1.json` on every host, SHA-256
`ce249995443ed3299c40c7dd6abdf06c8bf013593b16b662d9057b2a07b06366`.

Decision: eligible for controlled promotion, supported by this combined trial
and the earlier independent AVX-512 trial. Promotion and verification of the
new canonical configuration remain pending. No AITER or Dynamo GPU work ran
during these measurements; their source reviews were local. The subsequent
AITER import probes ran only after all model benchmarks completed.
