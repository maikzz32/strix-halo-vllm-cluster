# W1 workgroup scheduling and cache hints

Two isolated Node18 trials support testing expert-major W1 scheduling in the model. No serving source or configuration was changed; the canonical W2+AVX512 run remains active.

The M4/top10/E512/N320/K2560 asymmetric INT4 kernel retains BM16/BN64/BK128/SplitK4, stages2 and warps4. Only the mapping from launch coordinates to the existing (expert-block, output-tile, K-split) work item changes. Both mappings are bijections over the 800 work items. Every work item's dequantization, FP32 accumulation and final split reduction stay unchanged. The installed implementation remains the reference.

Each trial checks three routing patterns and 24 rotating banks, with full 512-expert weights and bitwise output comparison. Captured graphs are checked again after input changes. Timing uses five alternating traversal-order samples; each sample contains 20 graph replays with 24 calls each. Both candidates pass all 72 cases and graph checks in both seeds. This covers the tested positive-expert TP4 shape, not every MoE configuration.

The broad-routing benefit repeats: roughly 9-10% less W1 time for overlap25 and 3-4% for disjoint40. Reuse10 has no consistent benefit. Timings drift within some samples, so these are not statistical confidence bounds. None of these percentages are model token/s gains.

An earlier cache-hint trial modifies only the three weight/scale/zero-point loads. `.cg` is essentially unchanged (below 0.5% difference); `.cv` is much slower. Both are bitwise correct in the same bounded tests. Neither is proposed for serving.

`tools/patch_moe_w1_order.py` builds an opt-in `STRIX_MOE_W1_EXPERT_ORDER=1` candidate from the pinned W2-enabled source. It selects K-fast scheduling only for the tested W1 dimensions and grid, retaining the original driver for other cases. Candidate syntax and work-item bijection are checked locally; actual driver-dispatch validation and the full-model comparison are still pending. The generated kernel files gained license headers after the recorded tests; original exact tested source bytes are preserved in each local result directory.

All three GPU test processes exited with no owned processes remaining. Model counters stayed unchanged and queues empty. [Trial records](../bench/records/2026-09-07-moe-w1-order.json).
